## Analisis dan gate G-STD-01

VAL-001 memerlukan akses sah dokumen lengkap, identifikasi klausul relevan, cross-check metode/configuration assumptions,
hasil perhitungan independen, nama/identitas reviewer serta tanggal. Bukti minimal: standar+edisi+klausul+ringkasan applicability,
hasil check, gap, dan keputusan. Bila belum tersedia, task mencatat blocked pada signoff, bukan membuat klaim compliance.
Coding fixture dan UI tetap dapat maju; operationalReady=false.

Skill `standards-lookup` dan `technical-writing` tidak ditemukan dalam katalog skill lokal sesi penyusunan.
Metadata diverifikasi langsung pada penerbit; verifikasi klausul tetap terbuka. Periksa lagi ketersediaan skill saat pekerjaan terkait dilakukan.
