**Status:** paket instruksi sebelum coding. Tidak ada task aplikasi yang sudah diimplementasikan.

| Kebutuhan | Baca |
|---|---|
| Melanjutkan sesi | [HANDOFF](HANDOFF.md), [TASK_INDEX](TASK_INDEX.md), satu task card |
| Mengetahui produk | [PROJECT_BRIEF](PROJECT_BRIEF.md) |
| Menjaga keputusan | [DECISIONS](DECISIONS.md), [ARCHITECTURE](ARCHITECTURE.md) |

`TASK_INDEX` adalah status otoritatif. `PROGRESS` merangkum milestone; `HANDOFF` hanya titik lanjut terbaru.
Task ID stabil; jangan mengganti ID atau menghapus task yang diblokir. Tambahan scope diberi ID baru melalui amendment.
Identitas referensi teknis terpusat di [register standar](engineering/standards-register.md); card software merujuk kontraknya, bukan menyalin standar.
